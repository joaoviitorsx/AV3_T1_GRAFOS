# Como obter a evidência de *Accepted*

O enunciado exige uma **evidência clara do resultado Accepted** salva no
repositório. Esta evidência **só pode ser gerada pelo grupo**, fazendo a
submissão na plataforma oficial. Siga os passos abaixo.

## Passo a passo

1. **Crie uma conta** no UVA Online Judge: <https://onlinejudge.org/>
   (registro em *Register* — a conta é gratuita).

2. **Acesse o problema 1235**: *Anti Brute Force Lock*
   <https://uva.onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&page=show_problem&problem=3676>

3. **Submeta a solução**: em *Quick Submit*, selecione o problema **1235**,
   escolha a linguagem **Python 3** e envie o conteúdo do arquivo:

   ```text
   src/main.py
   ```

   > Observação: `src/main.py` é **autocontido** — usa apenas a biblioteca
   > padrão e lê de `stdin` / escreve em `stdout`, exatamente como a UVA exige.

4. **Aguarde o veredito** na página *My Submissions*. O resultado esperado é:

   ```text
   1235  Anti Brute Force Lock   Accepted
   ```

5. **Salve a evidência**: tire um print da página de submissões mostrando o
   **Accepted** e salve a imagem nesta pasta com o nome exato:

   ```text
   evidencias/accepted.png
   ```

   O `README.md` (seção 12) já referencia esse arquivo e passará a exibi-lo
   automaticamente.

## Checklist antes de enviar o link no AVA/Moodle

- [ ] `evidencias/accepted.png` adicionado e commitado
- [ ] nomes e matrículas dos integrantes preenchidos no `README.md`
- [ ] `apresentacao/apresentacao.pdf` presente
- [ ] repositório **público** no GitHub
- [ ] `git push` feito com todos os arquivos
